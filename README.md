## 它是做什么的

想显得亲切、可爱一点，可每次都要去翻颜文字库、手动挑一个贴上，一来二去就懒得弄了。

喵喵助手把这件事变成「顺手就发生」：你照常打字，按下发送之前，句尾的颜文字已经自己加好了。
它是一个纯粹的本机小工具 —— 打开无障碍就能用，不用注册、不用登录。

## 功能

- **打字即改写**：实时盯着聊天输入框，你打完停顿一下它就改写，不用点按钮、不用切来切去（触发延迟可在设置里调）
- **颜文字库可自定义**：内置一整套；能自己加（支持多行一次性粘贴）、删掉不喜欢的、一键恢复内置，重复的自动去重
- **QQ 与微信都支持**：微信从 8.0.52 起限制第三方无障碍读取界面节点（8.0.78 同样），本应用做了兼容处理，仍能正常改写
- **后台常驻不掉线**：走「无障碍 + Shizuku」双通道保活，**不需要 root、不需要刷机**，也不用一直挂在前台
- **四种主题**：跟随系统 / 浅色 / 深色 / AMOLED 四选一；AMOLED 模式纯黑背景并禁用壁纸，省电
- **毛玻璃界面**：卡片支持毛玻璃与模糊强度无级调节（壁纸模糊、卡片模糊分别可调）
- **自动检测更新**：打开应用自动看一眼有没有新版本（数据来自本仓库的 Release），也可以在设置里手动检测，或关掉这个开关

## 隐私与安全（可验证）

- **联网只用在一处**：只在「检测更新」时去本仓库的 Release 读一下最新版本号；**不下载、不上传任何数据**（检测更新可在设置里关掉）
- **不给服务器传东西**：不用注册账号、不用登录，聊天内容不会离开你的手机
- **不改别的应用**：只在聊天输入框里改写文字，不读聊天记录、不碰相册与通讯录

（应用申请的权限可在系统「设置 → 应用 → 喵喵助手 → 权限」里查看：无障碍、电池优化、网络三项。）

## 安装步骤

1. 点上面的**下载最新版 APK**，得到安装包
2. 在手机上打开它安装（首次会提示「允许安装未知应用」，同意即可）
3. 打开「喵喵助手」→ 进设置页 → 按提示打开**无障碍**权限
4. 在「已支持应用」里把 **QQ / 微信** 的开关打开（微信会先弹一次风险确认，需等 3 秒后确认）
5. 去聊天框打字试试 —— 发送前就能看到颜文字自动加上

**忘了原密码/需要帮助**：这是本地应用，不需要注册账号；如果界面卡住，杀掉进程重开即可。
