## 它是做什么的

你在聊天框里把话打完、按下发送之前，它自动在句尾加上颜文字 —— 不用你手动挑表情。
装一次、把无障碍打开，之后聊天时它自己在后台干活。

## 功能

- **打字即改写**：实时触发，发送前自动把话变可爱
- **颜文字可自定义**：内置一整套，也能加自己的、多行粘贴、一键恢复内置
- **QQ 与微信**：微信 8.0.52+ 限制第三方无障碍读取，本应用做了兼容处理
- **后台常驻**：无障碍 + Shizuku 双通道保活，不用一直挂在前台
- **界面**：Miuix 风格，支持浅色 / 深色 / 跟随系统 / AMOLED（AMOLED 下禁用壁纸省电）

## 安装步骤

1. 点上面的**下载最新版 APK**，得到安装包
2. 在手机上打开它安装（首次会提示「允许安装未知应用」，同意即可）
3. 打开「喵喵助手」→ 进设置页 → 按提示打开**无障碍**权限
4. 在「已支持应用」里把 **QQ / 微信** 的开关打开（微信会先弹一次风险确认，需等 3 秒后确认）
5. 去聊天框打字试试 —— 发送前就能看到颜文字自动加上

**忘了原密码/需要帮助**：这是本地应用，不需要注册账号；如果界面卡住，杀掉进程重开即可。
